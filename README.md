# PROTEUS explained

Visual introduction to how PROTEUS works: flow data, acoustics (k-Wave), microbubbles and image reconstruction.

Read it at https://theodore-michel.github.io/PROTEUS/

This branch only holds the slides; the code is on `revamp` (PROTEUS 1.1, in progress). `source/` has the scripts that made the figures: put them in a folder next to a PROTEUS checkout (`../PROTEUS`), with an `assets` folder, and run the MATLAB scripts, then `build_deck.py`.
